# Arrowlake for Tailwind CSS v4

The Arrowlake theme as Tailwind CSS theme color variables. Compatible with version 4 of Tailwind.

## Usage

1. Copy the theme CSS file(s) to your project.

2. Import in the CSS file to be processed by Tailwind CSS.

   ```css
   /* styles.css or whatever your CSS file is named */
   @import "tailwindcss";

   @import "./arrowlake_light.css";
   @import "./arrowlake_dark.css";
   ```

3. Use the theme's colors where ever you would normally reference colors.

   ```html
   <button class="border border-arrowlake-dark-border bg-arrowlake-dark-bg text-arrowlake-dark-fg">
     Click me!
   </button>
   ```
